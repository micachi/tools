Edge マネージドお気に入り生成

Microsoft Edge の ManagedFavorites ポリシー用 JSON を、フォルダツリーを編集するだけで生成します。 Intune の設定カタログ「お気に入りの構成」にそのまま貼り付けられます。

未指定だと既定名 Managed favorites になります。ユーザーはこのフォルダを変更できません（お気に入りバーから非表示にはできます）。

📥 既存 JSON をインポート

既に運用中の ManagedFavorites JSON を貼り付けるか、ファイルを読み込むと、上のツリー編集で変更できる状態に戻します。

フォルダの「＋🔖／＋📁」で中に入れ子にできます

スキーマの構造

配列の各要素が以下のいずれかです。フォルダは url キーを持たず、代わりに children を持ちます（この区別が必須）。

キー意味
toplevel_name格納フォルダ名（配列中どこか1つ）
name + urlブックマーク
name + childrenサブフォルダ（入れ子は再帰的に可能）

URL はスキーム無しでも Edge がアドレスバーと同じ補完をします（microsoft.com → https://microsoft.com/）。

⚠ 展開前に必ず知っておくこと

  • 「推奨」ポリシーでは使えません — mandatory（必須）のみ。Intune で「推奨値」としての構成はサポート外です
  • Microsoft アカウントでサインイン中のプロファイルには適用されません — Edge 116 以降の制限です。個人 Microsoft アカウント利用のプロファイルには効かないため、Entra ID（Azure AD） joined / WorkProfile 前提で設計してください
  • ユーザーアカウントへは同期されません — 意図的に同期対象外。拡張機能からの変更も不可
  • ユーザーはフォルダを編集できないが非表示にできる — 「表示しない」を選ばれたら検知できません
  • 対応バージョン — Windows ≥ 77 / macOS ≥ 77 / Android ≥ 30 / iOS ≥ 85
  • 動的ポリシー反映 — 対応。再ログインを待たずに反映されます

Intune での投入先

  1. Intune 管理センター → デバイス → 構成ポリシー → 作成 → Windows 10以降
  2. 設定カタログを検索: 「お気に入りの構成」／「Configure favorites」（ManagedFavorites）
  3. 生成した JSON を貼り付け → 対象グループに割り当て
