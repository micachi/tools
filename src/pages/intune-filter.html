Intune 割り当てフィルター 生成

Microsoft Intune の割り当てフィルター（ルール構文）を、プロパティと演算子を選ぶだけで生成します。 プロパティ名・演算子・値の制約は公式リファレンス準拠で、不正な組み合わせはその場でエラーになります。

よく使うフィルターを読み込む

「＋ グループ追加」で and / or を括弧でくくった入れ子を作れます。グループごとの結合子は左上のセレクトで変更します。

書式

([entity].[property name] [operation] [value])　— Entra の動的グループに似た形式です。

  • プロパティ・演算子・値は大文字小文字を区別しません
  • 括弧と入れ子がサポートされます（Intune 本体では入れ子を使うと簡易ルールビルダーは無効になり、ルール構文エディターでのみ編集可能。本ツールなら「グループ」で入れ子を作成・編集できます）
  • Null / $Null は -eq / -ne でのみ使用可
  • テナントあたり 200 個まで、1フィルター 3,072 文字まで

演算子

演算子 意味 値の形
-and / -or条件の結合—
-eq / -ne等しい / 等しくない文字列・配列・Null
-gt / -lt / -ge / -le大小比較operatingSystemVersion のみ
-startsWithで始まる文字列
-contains / -notContainsを含む / を含まない文字列
-in / -notIn配列に含まれる / 含まれない["a","b"]

展開時の注意

  • フィルターは「グループ」ではなく「絞り込み」 — 割り当て時に Include / Exclude で重ねる前提です
  • 評価タイミング — デバイスの登録時・Intune へのチェックイン時など、ポリシー評価の都度。動的グループのようなメンバー処理遅延はありません
  • 動的グループとの使い分け — Conditional Access やライセンスなどワークロード横断が必要なら動的グループ、Intune 固有のデバイス絞り込みならフィルターが向いています
  • 管理アプリ用フィルター — アプリ保護ポリシーとアプリ構成ポリシーにのみ適用され、コンプライアンスやデバイス構成プロファイルには適用されません
  • Android デバイス管理者（DA）は非推奨 — GMS 搭載デバイスでは利用不可。他の管理方式への移行が推奨されています
