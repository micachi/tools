Microsoft Graph（Intune）照会スニペット生成

Intune の deviceManagement 系リソースに対する Microsoft Graph クエリを組み立て、 URL / PowerShell（Graph SDK）/ curl の 3 形で出力します。リソースパスと必要なアプリ権限は公式ドキュメント準拠です。

認証のしかた

  • アプリ登録（client credentials）が基本。Entra ID にアプリ登録 → アプリ権限（Application permission）を付与 → 管理者同意 → シークレット取得
  • 対話型なら Connect-MgGraph -Scopes "..."（ delegated ）でも可。ただし必要権限はアプリ権限側で定義されています
  • Graph ポータルで試す: https://developer.microsoft.com/graph/geek-out の /beta/deviceManagement/…

落とし穴

  • Intune 割り当てフィルターの構文とは別物 — Graph OData は eq / startswith、Intune フィルターは -eq / -startsWith。混えると 400 が返ります
  • v1.0 に無いプロパティは beta — beta は変更される前提。本番スクリプトは v1.0 を優先してください
  • $count を使うなら ConsistencyLevel: eventual が必須 — 無いと 400 が返ります（curl 出力には付与済み）
  • 既定のページング — 1 回の応答は上限付き。@odata.nextLink を辿る必要があります
  • $select を省くと応答が重い — 大きなテナントでは時間がかかります。必要な列だけにしてください

参考: Microsoft Learn — Configure Microsoft Graph API access for Intune
