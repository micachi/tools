JSON 整形・バリデーション

貼り付けると即座に判定。エラーは行と列を指し示します。JSON の処理はすべてブラウザ内で行われ、貼り付けた内容がサーバーに送られることはありません。
※ ページ自体は広告（Google AdSense）を読み込みます。

インデント

よくあるエラー

  • 末尾カンマ — [1, 2, ] は JSON では不可（JS の配列リテラルと違う）
  • シングルクォート — キーと文字列は必ずダブルクォート
  • コメント — // や /* */ は非対応
  • NaN / Infinity — 数値として表現できない（null を使う）

「\u65e5\u672c\u8a9e」のようにエスケープされた日本語は「\uエスケープ解除」で可読化できます。
