管理対象ブックマーク生成（Edge / Chrome）

ブラウザの管理用ブックマークを、フォルダツリーを編集するだけで生成します。 Edge の ManagedFavorites と Chrome の ManagedBookmarks は JSON スキーマが完全同一なので、一度作ればターゲットの切り替えだけで両方に使えます。

展開対象ブラウザ

ポリシー名: ManagedFavorites　／ Windows レジストリ: SOFTWARE\Policies\Microsoft\Edge　／ macOS: com.microsoft.Edge

未指定だと各ブラウザの既定名になります。ユーザーはこのフォルダを変更できません（ブックマークバーから非表示にはできます）。

フォルダの「＋🔖／＋📁」で中に入れ子にできます

スキーマの構造（Edge / Chrome 共通）

配列の各要素が以下のいずれかです。フォルダは url キーを持たず、代わりに children を持ちます（この区別が必須）。

キー意味
toplevel_name格納フォルダ名（配列中どこか1つ）
name + urlブックマーク
name + childrenサブフォルダ（入れ子は再帰的に可能）

URL はスキーム無しでもブラウザがアドレスバーと同じ補完をします（example.com → https://example.com/）。

⚠ 展開前に必ず知っておくこと

共通事項：ユーザーアカウントへ同期されず、拡張機能からの変更もできません。ユーザーはフォルダを非表示にできます（検知不可）。

  • 「推奨」ポリシーでは使えません — mandatory（必須）のみ。Intune で「推奨値」としての構成はサポート外です
  • Microsoft アカウントでサインイン中のプロファイルには適用されません — Edge 116 以降の制限。Entra ID joined / WorkProfile 前提で設計してください
  • 対応バージョン — Windows / macOS ≥ 77 ／ Android ≥ 30 ／ iOS ≥ 85
  • 動的ポリシー反映 — 対応。再ログインを待たずに反映されます
  • 前提として「管理下であること」が必要 — Chrome は管理登録されていないマシンではポリシーを読みません。レジストリや管理設定を書いても無効です。先に Chrome Browser Cloud Management またはオンプレ管理（GPO / 管理設定）へ登録してください
  • ドメイン参加だけでは足りません — Chrome は管理元を検出してからポリシーを適用します（chrome://policy で反映状況を確認できます）
  • 対応バージョン — Chrome ≥ 37 ／ ChromeOS ≥ 37 ／ Android ≥ 30 ／ iOS ≥ 88
  • 動的ポリシー反映 — 対応 ／ プロファイル単位適用 — 対応
  • 個人 Google アカウントのプロファイル — 管理がブラウザ単位のため、個人用プロファイルにも適用され得ます。分離したい場合はプロファイル管理を別途設計してください

展開先

  1. Intune 管理センター → デバイス → 構成ポリシー → 作成 → Windows 10以降
  2. 設定カタログを検索: 「お気に入りの構成」／「Configure favorites」（ManagedFavorites）
  3. 生成した JSON を貼り付け → 対象グループに割り当て

参考: Microsoft Learn — ManagedFavorites policy

  1. Google Admin コンソール → デバイス → Chrome → 設定 → ユーザーおよびブラウザの設定
  2. 検索で 「管理対象のブックマーク」／「Managed bookmarks」（ManagedBookmarks）を選択
  3. 生成した JSON を貼り付け → 対象組織ユニットに適用

オンプレ管理の場合は chrome.admx（GPO）または macOS の管理設定 com.google.Chrome を使用。
反映の確認はクライアントで chrome://policy を開いてください。 参考: Chrome Enterprise — ManagedBookmarks
