Intune スタートメニュー レイアウト生成

Windows 11 の LayoutModification.json を、ピン留めを選ぶだけで生成します。 Microsoft Intune の設定カタログ「[スタート] のレイアウト」にそのまま投入できます。

適用ポリシー（applyOnce）

false（既定）= ログインごとに再適用され、ユーザーが並べ替えてもリセットされます。
true = 初回のみ適用。以降はユーザーの自由。

⚠ applyOnce は Windows 11 バージョン 24H2 KB5062660 以降でのみサポートされます。 それ以前のビルドでは無視されるため、ユーザー変更がリセットされ続けます。展開対象のビルドを確認してください。
よく使うアプリを素早く追加

4種類のピン方式（1エントリにつき1つだけ）

キー用途値の形式
packagedAppIdUWP / Microsoft Store アプリAUMID
desktopAppIdAUMID を持つデスクトップアプリAUMID
desktopAppLinkAUMID が無いデスクトップアプリ.lnk へのパス
secondaryTileMicrosoft Edge のサイトピンオブジェクト

展開前に必ず確認してほしいこと

  • ショートカットの配置場所 — desktopAppLink で指す .lnk は、対象デバイス全てに同じパスで存在する必要があります。推奨配置先は %ProgramData%\Microsoft\Windows\Start Menu\Programs
  • 実行ファイルの直接配置は無意味 — そのフォルダに exe やスクリプトを置いてもピン留めされません。.lnk が必要です
  • AUMID は実機で確認を — Get-StartApps（PowerShell）で一覧取得できます。プリセットの「一般に既知」欄はバージョンにより異なる可能性があります
  • 完全適用 vs 部分適用 — 完全適用するとユーザーはスタートへのピン留め／解除ができなくなります。部分適用（OnlySpecifiedGroups）は XML 側の構文で、JSON 形式では扱えません
  • Intune での投入先 — 設定カタログ → 「[スタート] のレイアウト」→ 生成した JSON を貼り付け
