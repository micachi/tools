Edge Managed Favorites Generator

Generate ManagedFavorites policy JSON for Microsoft Edge by editing a folder tree. Paste it straight into the Intune settings catalog: "Configure favorites".

If omitted, the default name Managed favorites is used. Users cannot modify this folder (though they can hide it from the favorites bar).

Use ＋🔖 / ＋📁 on a folder to nest inside it

Schema

Each element of the array is one of the following. A folder has no url key and instead carries children — this distinction is mandatory.

KeyMeaning
toplevel_nameName of the containing folder (exactly one, anywhere in the array)
name + urlA bookmark
name + childrenA subfolder (nesting recurses)

URLs without a scheme are completed by Edge exactly as if typed in the address bar (microsoft.com → https://microsoft.com/).

⚠ Read before deploying

  • Cannot be used as a "Recommended" policy — mandatory only. Configuring it as a recommended value is unsupported
  • Does not apply to profiles signed in with a Microsoft account — an Edge 116+ restriction. It will not land on personal-MSA profiles, so design for Entra ID joined / WorkProfile
  • Not synced to the user account — deliberately out of sync scope, and extensions cannot modify it either
  • Users cannot edit the folder but can hide it — if they choose not to show it, you cannot detect that
  • Supported versions — Windows ≥ 77 / macOS ≥ 77 / Android ≥ 30 / iOS ≥ 85
  • Dynamic policy refresh — supported; applies without waiting for re-login

Where to put it in Intune

  1. Intune admin center → Devices → Configuration policies → Create → Windows 10 and later
  2. Search the settings catalog for "Configure favorites" (ManagedFavorites)
  3. Paste the generated JSON → assign to your target group
