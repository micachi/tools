Managed Bookmarks Generator (Edge / Chrome)

Build managed browser bookmarks by editing a folder tree. Edge's ManagedFavorites and Chrome's ManagedBookmarks share an identical JSON schema, so you build once and switch targets.

Deployment target

Policy: ManagedFavorites / Windows registry: SOFTWARE\Policies\Microsoft\Edge / macOS: com.microsoft.Edge

If omitted, each browser's default name is used. Users cannot modify this folder (though they can hide it from the bookmark bar).

Use ＋🔖 / ＋📁 on a folder to nest inside it

Schema (identical for Edge and Chrome)

Each array element is one of the following. A folder has no url key and instead carries children — this distinction is mandatory.

KeyMeaning
toplevel_nameName of the containing folder (exactly one, anywhere in the array)
name + urlA bookmark
name + childrenA subfolder (nesting recurses)

URLs without a scheme are completed by the browser exactly as if typed in the address bar (example.com → https://example.com/).

⚠ Read before deploying

Common to both: managed bookmarks are not synced to the user account and cannot be modified by extensions. Users can hide the folder (which you cannot detect).

  • Cannot be used as a "Recommended" policy — mandatory only. Configuring it as a recommended value is unsupported
  • Does not apply to profiles signed in with a Microsoft account — an Edge 116+ restriction. Design for Entra ID joined / WorkProfile
  • Supported versions — Windows / macOS ≥ 77 / Android ≥ 30 / iOS ≥ 85
  • Dynamic policy refresh — supported; applies without waiting for re-login
  • The browser must be managed first — Chrome ignores policies on machines that are not enrolled. Writing the registry key or managed preferences does nothing on its own. Enroll in Chrome Browser Cloud Management or on-premises management (GPO / managed settings) first
  • Domain join alone is not enough — Chrome applies policies only after it detects a management source. Check chrome://policy on the client to confirm what actually landed
  • Supported versions — Chrome ≥ 37 / ChromeOS ≥ 37 / Android ≥ 30 / iOS ≥ 88
  • Dynamic policy refresh — supported / per-profile — supported
  • Personal Google accounts — management is browser-wide, so the policy can land on personal profiles too. Plan profile separation separately if you need it

Where to deploy

  1. Intune admin center → Devices → Configuration policies → Create → Windows 10 and later
  2. Search the settings catalog for "Configure favorites" (ManagedFavorites)
  3. Paste the generated JSON → assign to your target group

Reference: Microsoft Learn — ManagedFavorites policy

  1. Google Admin console → Devices → Chrome → Settings → User and browser settings
  2. Search for "Managed bookmarks" (ManagedBookmarks)
  3. Paste the generated JSON → apply to your target organizational unit

For on-premises management use chrome.admx (GPO) or the macOS managed setting com.google.Chrome.
