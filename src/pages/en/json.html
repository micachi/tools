Paste and get an instant verdict. Errors point to the line and column. All JSON processing happens in the browser — what you paste is never sent to a server.

Common errors

  • Trailing comma — [1, 2, ] is not valid JSON (unlike a JS array literal)
  • Single quotes — keys and strings must use double quotes
  • Comments — // and /* */ are not supported
  • NaN / Infinity — cannot be represented as JSON numbers (use null)

Escaped non-ASCII such as \u65e5\u672c\u8a9e can be turned back into readable text with "Unescape \u".
