Intune Start Menu Layout Generator

Build a Windows 11 LayoutModification.json just by picking pinned apps. Paste it straight into the Intune settings catalog: "Start layout".

Enforcement policy (applyOnce)

false (default) = re-applied at every sign-in, so the user's own arrangement gets reset.
true = applied on first pass only; the user owns it afterwards.

⚠ applyOnce is supported only on Windows 11 24H2 KB5062660 and later. On earlier builds it is ignored, so user changes keep getting reset. Check your target builds before deploying.

Check this before you deploy

  • Where the shortcut lives — the .lnk referenced by desktopAppLink must exist at the same path on every target device. Recommended location: %ProgramData%\Microsoft\Windows\Start Menu\Programs
  • Dropping the exe there does nothing — an exe or script in that folder will not pin. You need a .lnk
  • Verify AUMIDs on a real machine — use Get-StartApps (PowerShell). The "generally known" presets may differ by version
  • Full vs partial layout — a full layout stops users pinning or unpinning anything. Partial (OnlySpecifiedGroups) is XML-side syntax and cannot be expressed in the JSON format
  • Where to put it in Intune — Settings catalog → "Start layout" → paste the generated JSON
