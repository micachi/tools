Intune OMA-URI / Windows CSP 検索

Intune のカスタム設定で使う OMA-URI を、公式の 「Graph API プロパティ → Windows CSP」対応表 732 件から検索して合成します。 OMA-URI は CSP ルート + Offset URI の連結。先頭 ./ や Vendor/MSFT/ の形式検証つきです。

OMA-URI ビルダー

スコープの意味

  • ./Device/Vendor/MSFT/… — デバイス単位。ユーザーごとに変わらない設定はこちら
  • ./User/Vendor/MSFT/… — ユーザー単位。ログオンしたユーザーに適用される設定
  • ./Vendor/MSFT/… — Device / User 両対応。割り当て対象で決まります

カスタム OMA-URI 設定は「設定カタログに無い設定を投入する最後の手段」です。まず設定カタログとポリシーテンプレートを探し、無い場合に使ってください。

よく使う CSP ルート

  • ./Device/Vendor/MSFT/Policy/Config/… — ポリシー系（Administrative Templates 相当）の最大系統
  • ./Device/Vendor/MSFT/BitLocker/… — BitLocker 暗号化
  • ./Device/Vendor/MSFT/Firewall/… — Windows Firewall プロファイル
  • ./Device/Vendor/MSFT/PassportForWork/… — Windows Hello for Business
  • ./Device/Vendor/MSFT/AssignedAccess/… — Kiosk / 割り当てアクセス
  • ./Vendor/MSFT/Defender/… — Microsoft Defender（Device / User 両対応）

出典: Microsoft Learn — Graph APIs and matching Windows CSPs used in Intune ／ CSP 詳細は Windows MDM CSP リファレンス

運用メモ

  • Offset URI は 1 つとは限らない — 同じ CSP に複数 Offset があります。上のセレクトで全候補を確認できます
  • 数据类型（Data type）を間違えると不適用 — 整数 / 文字列 / 真偽 / XML を CSP リファレンスで確認してください
  • 連結時の二重スラッシュが最頻出のエラー — 本ツールは末尾スラッシュを整形してから連結します
  • 対応表は Graph 起点 — Graph の管理単位と CSP の対応を示したもので、全 CSP を網羅するものではありません
