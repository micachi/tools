便利ツール集

ブラウザだけで完結する、日常で使える小ツール。ツールへ入力した内容はサーバーに送信されません。インストール不要・会員登録不要・無料。

▦

QRコード生成

テキストやURLからQRコードを即生成。日本語対応、復元レベル・サイズ指定、PNGダウンロード可。

開く → ¶

文字数カウンター

書記素・コードポイント・バイト数・行数をリアルタイム集計。X(Twitter)280字判定と全角→半角変換つき。

開く → ◐

色・コントラスト検査

HEX/RGB/HSL変換と、WCAG AA/AAA 準拠のコントラスト比を自動判定。配色の読みやすさを確認。

開く → { }

JSON 整形・検証

貼り付けで即判定。エラーは行と列を指し示し、インデント変更・圧縮・\uエスケープ解除に対応。

開く → ⇄

単位変換

長さ・重さ・面積・容量・温度・データ・速さ・時間。匁・坪・升など和単位も含め全単位へ同時変換。

開く → 📅

日付計算

日付の加算・2日付の差・営業日数・満年齢。UTC基準でタイムゾーン由来のズレを排除。

開く → ⊞

Intune スタートレイアウト生成

Windows 11 の LayoutModification.json を生成。Intune 設定カタログにそのまま投入でき、applyOnce の制限や AUMID 形式を検証。

開く → ⭐

Edge マネージドお気に入り

ManagedFavorites ポリシー用 JSON をフォルダツリー編集で生成。入れ子構造・検証つきで Intune に投入できます。

開く → ⚿

パスワード一括生成

暗号学的乱数で複数パスワードを一括生成。個数・文字数・文字種を指定でき、生成処理はブラウザ内で完結します。

開く →

共通の設計思想

  • すべてクライアントサイド（JavaScript）で完結 — ツールへの入力内容はサーバーに送信されません
  • インストール不要・会員登録不要・無料
  • オフライン動作対応（ページを保存すればネット無しでも利用可）
  • スマホ対応
